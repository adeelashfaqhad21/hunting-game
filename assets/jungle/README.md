# Jungle & Forest Ecosystem Asset Pack

Game-ready low-to-mid poly .OBJ assets for the Hunting Game.

**Scale:** 1 unit = 1 meter  
**Forward:** +Z  
**Up:** +Y  
**Pivot:** Ground level (0,0,0)

## Structure

- `materials/jungle_ecosystem.mtl` — Shared PBR material library
- `terrain/` — Modular elevation pieces (high ground, depressions, crevices, cliffs, root networks)
- `trees/` — Hero, large, medium, small broadleaf trees (high foliage, minimal pines)
- `undergrowth/` — Dense bushes, ferns, vines, mushrooms
- `fauna/` — Deer, Fox, Primate, Snake
- `props/` — Rocks, fallen logs, scatter

All models include per-vertex RGB colors to avoid black texture issues on mobile.
